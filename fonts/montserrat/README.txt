Montserrat — шрифт сайта, подключён локально
============================================

Автор: Джульета Улановски (Julieta Ulanovsky) и участники проекта Montserrat.
Исходный код шрифта: https://github.com/JulietaUla/Montserrat
Лицензия: SIL Open Font License 1.1 — полный текст в файле OFL.txt рядом.

Что разрешает лицензия: свободное использование, в том числе в коммерческих
проектах, размещение на сайте, изменение и распространение. Единственный
запрет — продавать сам шрифт отдельно. Условие: копии шрифта нужно
распространять вместе с текстом лицензии, поэтому OFL.txt лежит здесь же.

Что за файлы
------------
Четыре вариативных файла .woff2, по наборам символов. Один файл покрывает
начертания 400–600, поэтому отдельные файлы на каждую толщину не нужны.

  montserrat-cyrillic.woff2      кириллица               ~21 КБ
  montserrat-cyrillic-ext.woff2  кириллица расширенная   ~24 КБ
  montserrat-latin.woff2         латиница                ~35 КБ
  montserrat-latin-ext.woff2     латиница расширенная    ~67 КБ

Браузер скачивает только те наборы, символы которых есть на странице.

Подключение
-----------
css/fonts.css — по одному @font-face на файл, с указанием unicode-range.
Этот файл подключается первым на каждой странице, до reset.css.
Исключение: 404.html — там @font-face лежит внутри страницы, потому что она
отдаётся по любому адресу и внешние пути оттуда ломаются.

Как обновить
------------
Файлы получены из раздачи Google Fonts — это поднаборы официального шрифта,
уже сжатые в woff2 и без лишних метаданных. Если понадобится обновить:
взять новые файлы и unicode-range из Google Fonts (или собрать поднаборы из
исходников по ссылке выше), заменить файлы в этой папке, обновить
css/fonts.css и не забыть про копию в publish/fonts/montserrat/.
