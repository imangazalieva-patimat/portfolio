Навыки

Проектирование и UX
  • Брифинг и ТЗПроведение интервью с клиентом, составление технического задания.
  • UX-анализИсследование рынка, проведение конкурентного анализа и поиск референсов.
  • Формирование гипотезФормулирую UX-гипотезы на основе потребностей пользователя и проверяю их через прототипы.
  • ПрототипированиеНизко- и высокоуровневые прототипы для тестирования концепций.
  • Проектирование интерфейсовСоздание wireframes, JTBD, user flows, сценариев взаимодействия.
Рабочий процесс
  • Взаимодействие с менеджерами и разработчикамиВыстраиваю прозрачную коммуникацию и согласую решения на каждом этапе.
  • Передача макетовГотовлю макеты для удобной работы разработчиков: логичная структура, пояснения, поддержка на этапе вёрстки.
UI и дизайн-система
  • Уверенное владение FigmaИспользование auto layout, компонентов, вариантов, переменных, constraints.
  • Разработка UI-kitСоздание библиотеки компонентов, состояний, цветовых и текстовых стилей.
  • Опыт работы с дизайн-системамиИспользование существующих систем: понимание правил, адаптация под задачи.
  • Создание дизайн-системы с нуляКомпоненты, токены, переменные.
  • Адаптивный дизайнРазработка интерфейсов для разных экранов: desktop, tablet, mobile.
